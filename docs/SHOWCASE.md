# 给地瓜机器人开发者的项目介绍

**EAT-RDK：一次张嘴，如何选出一条水平送餐轨迹？**

我们把辅助进食中的一个具体问题做成了可复现的交互演示。使用者的嘴部位置会变化，程序需要判断何时开始，以及现有动作里哪一条能把勺子送到合适的位置。EAT-RDK 将单人唇部关键点、同帧深度查询和四轴机械臂运动学接起来。观众可以移动虚拟嘴部，直接比较 100 个送餐终点，看见最近距离和被选中的动作。

**建议用一分钟展示默认案例。** 先指向灰色候选点与粉色嘴部目标，点击模拟张嘴。F008 被选中，终点距离约 5.7 mm。播放时观察勺子在餐盘处下倾舀取，离开餐盘后保持水平，将食物呈递到嘴前，短暂停留后撤回。最后改变目标偏移再次触发，请观众对照前五名和新的轨迹编号。

**希望与 RDK 社区一起验证的内容**是 X5 上的 D455 同帧采集质量、板端浏览器与远端浏览器的延迟差异，以及将关键点检测迁移到 BPU 后的效果。当前发布包含桌面仿真验证、板端部署说明和用于对照的 CPU/WASM 路径。板端指标将在取得实际测量后补充。

项目代码与复现入口：[tree1129/EAT-RDK](https://github.com/tree1129/EAT-RDK)。
